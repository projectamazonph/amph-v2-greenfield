## What you can do after this lesson

Explain the workflow a real operator runs on a Search Query Performance (SQP) report, name the four ranks the data supports, and read the simulator's grade for "proved" vs "hinted" signals before you turn a hint into a bid or budget change.

## Why this workflow exists

A Search Query Performance report tells you how shoppers find your product and how each query converts. A real operator reads it the same way a doctor reads a chart: rank the most important signals, ignore the noise, and act only on what the data proves.

The SQP Studio sim is the practice surface. The lesson is the rank: by impressions, by clicks, by conversion rate, then by priority. The fourth rank is the one that protects you from acting on a hint.

## What the workflow looks like end to end

A production operator who reads SQP for a real account runs four ranks, in order:

1. **Rank by impressions.** Which queries get the most visibility? These are the queries Amazon already thinks are about your product. They are the ones to optimize first, because the data is already there.
2. **Rank by clicks.** Of those high-impression queries, which ones do shoppers actually click? The click-through rate separates "seen" from "considered."
3. **Rank by conversion.** Of those clicked queries, which ones turn into orders? A high-CTR, low-converting query is a listing problem, not a targeting problem. A low-CTR, high-converting query is an attention problem.
4. **Prioritize.** Decide which queries deserve a bid change, which deserve a negative, and which are noise. A query with high impressions, low clicks, and zero orders is a hint, not a fact. A query with high impressions, high clicks, and zero orders is closer to a fact.

The difference between a hint and a fact is the data behind it. A query with 4 clicks and 0 orders is a hint. A query with 60 clicks and 0 orders is a fact.

## How to read the simulator's feedback

SQP Studio grades you against four signals:

- **Impression rank.** Did you spot the queries Amazon already thinks are about your product?
- **Click rank.** Did you separate seen from considered?
- **Conversion rank.** Did you separate listing problems from targeting problems?
- **Hint vs fact.** Did you protect yourself from acting on a low-data signal?

A high score with no hint-vs-fact discipline is a long list of bid changes based on noise. A high score with explicit discipline is a short list of defensible actions.

## Check

## Key takeaway

Rank, then act. Match the action strength to the evidence strength. The SQP report is most useful when it tells you what you should not change.
