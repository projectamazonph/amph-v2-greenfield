## 🎯 Overview

The Project Amazon PH Academy provides comprehensive Amazon PPC (Pay-Per-Click) training for Filipino virtual assistants and eCommerce teams. The curriculum is designed to transform beginners into proficient Amazon PPC practitioners through a structured, hands-on learning approach.

**Core Philosophy:** "Read → Decide → Change → Explain" — every lesson follows this practical work loop.

**Target Audience:** Filipino virtual assistants, eCommerce teams, and Amazon sellers seeking to master Amazon PPC advertising.

A free set of SimGrid drills sits inside the existing modules: 0.4 AdConsole Pro and 0.5 Client Onboarding in Onboarding, 2.5 Keyword Lab in Keyword Research, 3.4 BuyBox Dojo in Listing Optimization, 4.5 Campaign Architect in Campaign Architecture, 6.4 Bid Decisions in Bidding Lab, 7.4 Search Term Triage in Search Term Triage, 9.4 Pacing Deck and 9.5 SQP Studio in Weekly Optimization, 10.5 Account Audit in Reporting and Troubleshooting, 11.5 Bulk File and 11.6 Capstone in VA Workflow and Capstone. Each drill is free for any signed-in student and does not gate course progression.

## 🎓 Learning Methodology

### **Work Loop**

Every lesson follows the **"Read → Decide → Change → Explain"** methodology:

1. **Read:** Absorb the lesson content and concepts
2. **Decide:** Make informed decisions based on the material
3. **Change:** Apply changes to campaigns or strategies
4. **Explain:** Articulate the reasoning behind decisions

### **Assessment Methods**

- **Module Quizzes:** 13 module-final quizzes with a 70% pass threshold
- **Practical Simulations:** 5 interactive tools for hands-on practice
- **XP System:** Experience points for engagement and progress tracking
- **Badges:** Achievement recognition for milestone completion

### **Simulation Tools**

| Tool             | Purpose                       | Status      |
| ---------------- | ----------------------------- | ----------- |
| Bid Elevator     | Practice bid optimization     | Implemented |
| STR Triage       | Search term analysis practice | Implemented |
| Campaign Builder | Campaign structure practice   | Implemented |
| Listing Audit    | Listing optimization practice | Implemented |
| Keyword Research | Keyword discovery practice    | Implemented |

**Note:** Simulator scores are formative only and should not be used for certification or hiring evidence.
