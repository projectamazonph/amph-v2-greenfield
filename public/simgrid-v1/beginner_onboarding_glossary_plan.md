# VA Start Here: Onboarding and Quick Glossary Plan

## Purpose

This page is the first stop for a Filipino VA learner with no Amazon experience. It gives a short orientation, a safe first learning sequence, and a plain-English glossary that links every essential term back to the relevant PPC Coach module or simulator.

## Onboarding sequence

| Step                      | Learner action                                         | Why it comes first                                                 |
| ------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------ |
| 1. Read the map           | Learn what Amazon shoppers see before any ad decision. | A product page must be ready before paid traffic can help.         |
| 2. Learn the PPC path     | Follow Module 00, then Module 01 in PPC Coach.         | This separates product-page readiness from ad delivery.            |
| 3. Practice one safe task | Open BuyBox Dojo and check listing readiness.          | The learner practices observation before changing a campaign.      |
| 4. Use the glossary       | Return here when a new term appears.                   | The definition, use case, and relevant module remain easy to find. |

## Glossary groups

| Group             | Terms                                                                  |
| ----------------- | ---------------------------------------------------------------------- |
| Shopping basics   | Marketplace, listing, Buy Box, stock, organic traffic, paid traffic    |
| PPC basics        | PPC, impression, click, auction, bid, daily budget                     |
| Campaign language | Campaign, ad group, keyword, search term, match type, negative keyword |
| Result language   | CPC, CTR, conversion rate, ACOS, ROAS, break-even ACOS                 |
| Safe VA work      | Search-term report, SOP, change log, approval task                     |

Each glossary row will state the **plain meaning**, **when a VA uses it**, and a direct **learn or practice** link. No row assumes existing Amazon knowledge.
