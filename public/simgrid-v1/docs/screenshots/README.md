## Gallery maintenance

The current gallery covers all 12 simulators plus PPC Coach, the planned simulators archive, and the learn & docs hub. When those pages materially change, recapture the same routes with the stable filenames above.

Additional useful captures for a future expanded gallery are:

1. A mobile hub capture when responsive behavior materially changes
2. Detailed drill-down captures for each simulator's main interaction

Use a desktop viewport and capture the first meaningful working state, not a loading screen. Add a second mobile capture only when it demonstrates a materially different responsive interaction. Keep filenames stable and descriptive so README links survive future recaptures.
