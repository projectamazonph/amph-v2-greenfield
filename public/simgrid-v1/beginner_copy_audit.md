# Beginner Copy Audit

This audit examines the 144 public module slides for copy density, sentence length, jargon clusters, and explicit learner direction. It is a revision guide rather than a curriculum-quality score.

| Measure                    |                                   Result |
| -------------------------- | ---------------------------------------: |
| Slides reviewed            |                                      144 |
| Slides flagged for rewrite |                                        0 |
| Density threshold          |                      More than 115 words |
| Sentence threshold         |            More than 24 words on average |
| Jargon threshold           | More than 3 essential terms on one slide |

| Module | Slide | Words | Avg. words per sentence | Essential terms present | Rewrite reason |

## Rewrite rule

For every flagged slide, keep the core learning outcome, replace specialist phrasing with a first-use definition, use one short familiar situation, and end with one clear learner action.
