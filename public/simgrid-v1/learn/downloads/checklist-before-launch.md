# Checklist — Before You Launch

Run this the day before a new campaign goes live. If any box is empty,
fix it before you turn the campaign on.

## Listing

- [ ] Title is keyword-rich, under 200 characters, readable.
- [ ] Five bullet points, each leading with a benefit.
- [ ] A+ content (or at minimum a strong product description).
- [ ] 7+ images, including lifestyle, infographic, size/scale, and the
      hero shot on a clean background.
- [ ] Price is competitive in the niche (check the top 10 competitors).
- [ ] 15+ reviews, average 4.0+ stars, or a written plan to get them
      within the first 30 days.
- [ ] All variants the campaign will advertise are in stock.

## Buy Box & inventory

- [ ] Buy Box is yours at 100% for the last 14 days.
- [ ] If not, you have a clear fallback (FBA-in, sole seller, or
      explicit owner approval to advertise on a partial Buy Box).
- [ ] Inventory covers the test window: at least 8 weeks of stock at
      expected daily sales. Run-out mid-test makes the data unusable.

## Structure

- [ ] Campaign naming follows the standard
      (`ProductLine · Targeting · MatchType · Goal`).
- [ ] One match type per ad group — never Exact and Broad in the same group.
- [ ] Budgets are isolated per campaign — no shared daily caps that
      starve the test.
- [ ] Portfolios (or labels) are set so the campaign is findable in 5
      seconds in the UI.

## Bids & negatives

- [ ] Bids start at or below Amazon's suggested bid for new campaigns.
      You can raise _after_ data; you can't un-spend an overbid.
- [ ] Negative keywords seeded with the obvious irrelevants: free,
      used, knockoff, repair, manual, alternative, DIY, cheap.
- [ ] Default bid adjustments: Top-of-Search 0%, Product Pages 0%.
      You'll add them later, on winners.

## Documentation

- [ ] Goals written down — what does success look like at 14 days?
      At 28 days?
- [ ] Forecast written down — expected daily spend, expected daily
      sales, expected ACOS at week 4.
- [ ] Change log started — first entry:
      `"Launch, all defaults, no edits yet."`
- [ ] Owner noted — whose name is on this campaign for review.

## Last gate

- [ ] I have read the boring four (stock, price, reviews, competitor)
      in the last hour. None of them is broken. I'm not about to
      optimize around a problem the listing created.
