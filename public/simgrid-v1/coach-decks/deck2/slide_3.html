Decision-Ready SP | Auto | Bamboo Board | Research
Ad Type Targeting Product Purpose
✅ Do
  • Include the ad type (SP, SB, SD)
  • Include the targeting type (Auto, Exact, etc.)
  • Include the product name
  • Include the purpose (Research, Core, etc.)
🚫 Don't
  • Use names like "test1", "final2", "new-new"
  • Use names only you can guess
  • Put everything into one giant campaign
Coach tip: Good naming is not cosmetic. It is how you move fast without breaking things.
