Why bulk ops

The console is for looking. The bulk file is for moving.

Agencies don't click through the Ads Console for 500 keywords. They write one file, upload it, and let Amazon process every row top to bottom.

01

Download

Get the bulk template from the Ads Console or your manager. It reflects the account's current campaigns and IDs.

02

Edit

Add rows for new entities, change values for updates. Parents muna, children after — laging ganito.

03

Upload

Upload the file. Amazon validates every row — ang isang maling row ay pwedeng mag-fail ng buong group.

04

Process

Amazon applies the operations. Your temporary IDs are replaced with real account IDs.

05

Verify

Download again and confirm the change landed. Hindi tapos ang trabaho hangga't hindi verified.

FN-01

Row order is law

Amazon processes top to bottom. A keyword row above its ad group fails with "parent not found." Structure: Portfolio → Campaign → Ad Group → children.

FN-02

Temporary IDs on Create

Amazon doesn't know the new campaign yet, so you name it yourself — tmp-camp-101. Child rows reference it. After processing, Amazon swaps in real IDs.

FN-03

Update & Delete need real IDs

Never by name. Download the current file first, copy the IDs, then write your update rows. Ito ang pinaka-common na pagkakamali ng bagong VA.

Six short lessons. Basahin sa order — bawat isa ay may "Try it" na nakadugtong mismo sa simulator sa baba.

A bulk file is a spreadsheet where every row is one instruction: create this, change that, delete this. Sa console, isa-isang click. Sa bulk file, 500 keywords in one upload.

The training file has 32 columns, but most rows use only a few. Empty cells are normal. Ang importante: tama ang required fields para sa entity ng row.

Entity      Operation   Campaign ID      Campaign Name            Daily Budget
Campaign    Create      tmp-camp-101     THP-Bamboo-SP-Auto       25.00
Ad Group    Create      tmp-adg-101      THP-Bamboo-Auto          —
Keyword     Create      tmp-kw-101       (manual campaign only)   —

Sponsored Products is a tree: Portfolio → Campaign → Ad Group → children. The rule that never bends: parents appear before children. Pag nauna ang anak, "parent not found" ang sagot.

On Create, rows are linked by temporary IDs — tmp-camp-101. After upload, Amazon replaces them with real IDs. Kaya sa susunod mong download, iba na ang mga ID.

✓  Portfolio → Campaign → Ad Group → Keyword        (tanggap)
✗  Keyword → Ad Group → Campaign                    ("parent not found")

Create — temporary ID. Update — fill only what changes and reference the entity by its real ID from your latest download, never by name. Delete — permanent; i-double-check ang ID.

Bulk files don't move keywords: create it in the new campaign, negative it in the old one.

Create   →  temporary ID        tmp-camp-101
Update   →  real ID             1001        (from latest download)
Delete   →  real ID             double-checked

Hard rules: Keywords and targeting expressions exist only in manual campaigns. Product Ads exist in both. Negative keywords exist in both.

The classic VA mistake: harvested terms nilagay pabalik sa auto campaign. The right flow: converters become exact keywords in a new manual campaign, and the auto campaign gets negatives para hindi na maulit.

AUTO campaign      →  Product Ad ✓   Keyword ✗   Targeting ✗
MANUAL campaign    →  Product Ad ✓   Keyword ✓   Targeting ✓

Money lives at three levels: Daily Budget (campaign), Ad Group Default Bid (ad group), Bid (keyword/target). A keyword's own bid overrides the default. Format: 25.00 — hindi ₱25.

States: enabled, paused, archived. Pro move: upload a new campaign as paused, review, then enable with a second upload.

Campaign      Daily Budget       25.00
Ad Group      Default Bid         0.95
Keyword       Bid                 1.25   ← overrides the default

Negative keywords don't bid — they block. Ad Group negatives block within one ad group; Campaign negatives block across the whole campaign. Walang bid column — kailanman.

Targeting expressions are exact syntax, quote marks included. Every manual campaign ships with negatives from day one — free, cheap, used, jobs.

asin="B0COMPET01"
category="home & kitchen > kitchen & dining > coffee makers"

Glossary

Bulk file
A spreadsheet of Create/Update/Delete operations uploaded to Amazon Ads.
Entity
The object a row acts on: campaign, ad group, keyword, etc.
Temporary ID
Placeholder ID (tmp-…) used on Create so child rows can reference parents.
SKU
The seller's own catalog code for a product.
ASIN
Amazon's 10-character product code. Format: B + 9 characters.
Match type
How closely a search must match: exact, phrase, or broad.
Negative keyword
A term you block instead of bidding on.
Targeting expression
Exact syntax for targets: asin="…", category="…".
Placement
Where an ad shows: top of search, product pages, rest of search.
ACOS
Ad spend ÷ ad sales. The efficiency number clients ask about first.
Guardrail bid
Price × target ACOS × conversion rate — the bid the math supports.
Harvest
Moving converting auto search terms into a manual exact campaign.
