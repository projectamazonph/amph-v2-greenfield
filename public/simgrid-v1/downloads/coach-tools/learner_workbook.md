# Amazon PH Simulators — Learner Workbook

## How to use this workbook

Use each worksheet before opening the corresponding simulator. Write the evidence you observe, the inference you make, the action you propose, and the risk you accept. The goal is not to click quickly; it is to make a defensible decision and document why it should work.

## Worksheet 1 — Listing Readiness and Economics

**Scenario:** Bamboo Cutting Board. Decide whether the listing is ready for paid traffic, needs repair, or should be paused.

| Check                     | Evidence observed | Risk if ignored | Decision |
| ------------------------- | ----------------- | --------------- | -------- |
| Main image and title      |                   |                 |          |
| Price and offer           |                   |                 |          |
| Reviews and rating        |                   |                 |          |
| Inventory and Buy Box     |                   |                 |          |
| Relevance to target query |                   |                 |          |
| Contribution margin       |                   |                 |          |
| Break-even ACOS           |                   |                 |          |

Complete these calculations using the figures supplied by your instructor:

| Metric          | Formula              | Your calculation |
| --------------- | -------------------- | ---------------- |
| CPC             | Spend ÷ Clicks       |                  |
| CTR             | Clicks ÷ Impressions |                  |
| Conversion rate | Orders ÷ Clicks      |                  |
| ACOS            | Spend ÷ Sales        |                  |
| ROAS            | Sales ÷ Spend        |                  |
| Break-even ACOS | Contribution margin  |                  |

**Decision sentence:** “I would [advertise / repair / pause] because the evidence shows ____. The first action is ____; the risk I am controlling is ____.”

## Worksheet 3 — Controlled Launch Plan

Build a four-week launch sequence. Treat each week as a hypothesis, not a promise of performance.

| 1    | Discover          |                              |                     |                      |
| 2    | Validate          |                              |                     |                      |

**Pre-flight checklist:** Confirm listing readiness, budget availability, inventory, Buy Box eligibility, campaign naming, match-type intent, and change-log setup.
