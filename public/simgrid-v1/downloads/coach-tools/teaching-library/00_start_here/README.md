# Start Here — Expanded Teaching Library

This is the downloadable working library for the 12-module Amazon PPC Coach pathway. Begin with the field handout and learner worksheet for the current module, then use the matching template and automated workbook during simulator practice. Finish every working session by recording evidence, one safe action, a guardrail, an owner, and a review date.

## Quick path

1. Read the current module field handout.
2. Complete the learner worksheet before or during the simulator.
3. Use a decision cheat sheet while choosing actions.
4. Select the matching operating template or workbook.
5. Bring the final artifact to a facilitator debrief or capstone review.
