# Module 6 Decision Cheat Sheet — Campaign Setup

## One-line objective

Choose auto versus manual, build a safe starter structure, and plan a four-week launch.

> **Non-negotiable:** Launch with a learning plan, a budget guardrail, and a review date—not a pile of unowned targets.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                           | Use it to             |
| -------------------------------- | --------------------- |
| Listing readiness gate           | Observe before acting |
| Campaign purpose and naming      | Observe before acting |
| Auto / manual role               | Observe before acting |
| Week-by-week evidence milestones | Observe before acting |

## Safe action standard

Open only the campaigns you can explain, monitor, and change according to a named review cadence.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term              | Meaning                                                           |
| ----------------- | ----------------------------------------------------------------- |
| Auto campaign     | Amazon-directed discovery targeting.                              |
| Manual campaign   | Advertiser-selected targeting and match settings.                 |
| Launch hypothesis | A testable expectation about where early evidence will come from. |
| Guardrail         | A limit that prevents uncontrolled spend or risk.                 |
