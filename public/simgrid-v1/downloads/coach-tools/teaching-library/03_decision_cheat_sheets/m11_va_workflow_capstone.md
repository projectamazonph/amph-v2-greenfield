# Module 11 Decision Cheat Sheet — VA Workflow & Capstone

## One-line objective

Operate by cadence, respect permissions, use SOPs and change logs, and complete the capstone.

> **Non-negotiable:** A reliable operator knows what to do, what to log, what to notify, and what must be approved.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                                     | Use it to             |
| ------------------------------------------ | --------------------- |
| Task owner and due date                    | Observe before acting |
| Permission level                           | Observe before acting |
| Evidence artifact                          | Observe before acting |
| Escalation status and client communication | Observe before acting |

## Safe action standard

Act independently only within the permission level; notify or escalate when authority or risk requires it.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term              | Meaning                                                               |
| ----------------- | --------------------------------------------------------------------- |
| SOP               | Standard operating procedure; repeatable step sequence with controls. |
| Independent       | Action allowed without separate approval.                             |
| Notify            | Action allowed but must be reported to the owner.                     |
| Approval-required | Action cannot proceed until an authorized owner approves.             |
| Capstone          | Integrated performance task that demonstrates operational judgment.   |
