# Module 0 Decision Cheat Sheet — Amazon Basics

## One-line objective

Explain marketplace visibility, listing anatomy, organic versus paid traffic, and the Buy Box.

> **Non-negotiable:** Before touching traffic, make sure the product can win the click and the conversion.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                                 | Use it to             |
| -------------------------------------- | --------------------- |
| In-stock status and buyable offer      | Observe before acting |
| Price and coupon position              | Observe before acting |
| Review proof and image clarity         | Observe before acting |
| Search relevance and Buy Box ownership | Observe before acting |

## Safe action standard

Repair listing or offer friction before proposing a traffic increase.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term            | Meaning                                                          |
| --------------- | ---------------------------------------------------------------- |
| ASIN            | Amazon Standard Identification Number for the product record.    |
| Buy Box         | The preferred offer position that enables most purchase actions. |
| Organic traffic | Visits earned without an ad click.                               |
| Paid traffic    | Visits generated after an ad click.                              |
