# Module 8 Decision Cheat Sheet — Search Terms & Negatives

## One-line objective

Read reports, classify winners, wasters, and maybes, and run the weekly harvest loop.

> **Non-negotiable:** Harvest is a classification workflow: graduate, negate, lower / repair, or watch.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                                         | Use it to             |
| ---------------------------------------------- | --------------------- |
| Relevance to the product                       | Observe before acting |
| Clicks and orders                              | Observe before acting |
| ACOS versus the guardrail                      | Observe before acting |
| Existing campaign coverage and negative status | Observe before acting |

## Safe action standard

Make the smallest action that protects learning while controlling waste.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term    | Meaning                                                              |
| ------- | -------------------------------------------------------------------- |
| Harvest | Recurring review of search-term evidence for actionable discoveries. |
| Winner  | Relevant traffic meeting the economic and evidence rule.             |
| Waster  | Irrelevant or economically unacceptable traffic requiring control.   |
| Watch   | Insufficient evidence to change safely.                              |
