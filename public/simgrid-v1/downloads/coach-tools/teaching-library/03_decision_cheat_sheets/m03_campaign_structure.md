# Module 3 Decision Cheat Sheet — Campaign Structure

## One-line objective

Use campaign, ad-group, and targeting hierarchy; apply naming conventions; distinguish SP, SB, and SD.

> **Non-negotiable:** Structure exists to preserve control, reading clarity, and a clean next action.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                                      | Use it to             |
| ------------------------------------------- | --------------------- |
| One purpose per campaign                    | Observe before acting |
| Targeting and match-type separation         | Observe before acting |
| Traceable naming convention                 | Observe before acting |
| Evidence routing from search term to action | Observe before acting |

## Safe action standard

Separate intent or control levels when a combined structure prevents a clear decision.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term         | Meaning                                                              |
| ------------ | -------------------------------------------------------------------- |
| Campaign     | Budgeted container for a defined advertising objective.              |
| Ad group     | Sub-container that groups products and targets.                      |
| Target       | Keyword, product, category, or audience instruction for serving ads. |
| SP / SB / SD | Sponsored Products, Sponsored Brands, and Sponsored Display.         |
