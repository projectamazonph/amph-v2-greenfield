# Module 1 Decision Cheat Sheet — What is PPC?

## One-line objective

Explain PPC, auction logic, relevance, placements, and the click funnel.

> **Non-negotiable:** An ad is a route into a funnel, not a guarantee of a sale.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                             | Use it to             |
| ---------------------------------- | --------------------- |
| Search intent or shopper context   | Observe before acting |
| Bid competitiveness                | Observe before acting |
| Relevance of keyword to product    | Observe before acting |
| Listing conversion after the click | Observe before acting |

## Safe action standard

Use bids to compete for a relevant opportunity; use listing work to earn the order.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term       | Meaning                                                                 |
| ---------- | ----------------------------------------------------------------------- |
| PPC        | Pay-per-click advertising; cost is incurred when an ad is clicked.      |
| Auction    | The selection process that weighs bid and relevance for an opportunity. |
| Placement  | Where an ad can appear, such as search or product pages.                |
| Conversion | A desired outcome, commonly an order after a click.                     |
