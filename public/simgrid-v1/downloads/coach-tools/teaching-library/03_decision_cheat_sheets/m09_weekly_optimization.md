# Module 9 Decision Cheat Sheet — Weekly Optimization

## One-line objective

Run a weekly cadence, change one variable at a time, and use data thresholds.

> **Non-negotiable:** Observe, diagnose, hypothesize, change one variable, log, then review.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                            | Use it to             |
| --------------------------------- | --------------------- |
| Weekly baseline and delta         | Observe before acting |
| Single variable changed           | Observe before acting |
| Evidence threshold used           | Observe before acting |
| Result, learning, and next action | Observe before acting |

## Safe action standard

Do not stack multiple changes against the same problem when you need to know what caused the outcome.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term       | Meaning                                                   |
| ---------- | --------------------------------------------------------- |
| Hypothesis | A testable explanation for observed performance.          |
| Variable   | The one condition intentionally changed in an experiment. |
| Threshold  | The evidence rule that allows a decision.                 |
| Cadence    | The recurring operating rhythm for review and action.     |
