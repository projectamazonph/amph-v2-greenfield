# Module 4 Decision Cheat Sheet — Keywords & Match Types

## One-line objective

Distinguish keyword versus search term; apply broad, phrase, exact, and negatives; research terms.

> **Non-negotiable:** A keyword is your instruction; a search term is the shopper evidence you must classify.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                                | Use it to             |
| ------------------------------------- | --------------------- |
| Search-term relevance                 | Observe before acting |
| Click and order volume                | Observe before acting |
| ACOS versus margin guardrail          | Observe before acting |
| Match-type role and negative coverage | Observe before acting |

## Safe action standard

Promote proven relevance, block waste, lower only when relevance remains plausible, and watch when evidence is insufficient.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term        | Meaning                                                           |
| ----------- | ----------------------------------------------------------------- |
| Keyword     | A targeting instruction supplied by the advertiser.               |
| Search term | The shopper query that actually triggered an ad.                  |
| Broad       | A discovery-oriented match type with the widest controlled reach. |
| Phrase      | A match type that preserves phrase-level intent with variation.   |
| Exact       | A high-control match type for proven intent.                      |
| Negative    | An exclusion that blocks unwanted matching.                       |
