# Module 5 Decision Cheat Sheet — Listing Readiness

## One-line objective

Diagnose listing conversion leaks before increasing PPC pressure.

> **Non-negotiable:** Do not scale traffic into a conversion leak.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                                        | Use it to             |
| --------------------------------------------- | --------------------- |
| Stock and Buy Box status                      | Observe before acting |
| Price competitiveness                         | Observe before acting |
| Review count and rating signal                | Observe before acting |
| Main image, title, bullets, and offer clarity | Observe before acting |

## Safe action standard

Hold or limit traffic if the listing has an unresolved conversion-critical defect.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term            | Meaning                                                                   |
| --------------- | ------------------------------------------------------------------------- |
| Readiness gate  | A condition that must be met before a launch or scale decision.           |
| Conversion leak | A product-page or offer problem that prevents orders after clicks.        |
| Offer           | The sellable combination of price, availability, and fulfillment.         |
| Escalation      | A documented request for an owner with the authority to resolve an issue. |
