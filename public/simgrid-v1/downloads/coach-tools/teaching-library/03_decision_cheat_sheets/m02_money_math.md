# Module 2 Decision Cheat Sheet — Money Math

## One-line objective

Calculate CPC, CTR, conversion rate, ACOS, ROAS, TACoS, and break-even economics.

> **Non-negotiable:** Use the metric that identifies the leak; do not optimize a ratio without its denominator.

## Fast decision sequence

1. **Observe:** identify the signal and its source.
2. **Diagnose:** explain the most plausible leak or opportunity.
3. **Choose:** take the smallest safe action.
4. **Control:** name the guardrail and owner.
5. **Review:** set a date or evidence threshold.

## Signals at a glance

| Signal                                              | Use it to             |
| --------------------------------------------------- | --------------------- |
| Impressions and clicks for visibility and attention | Observe before acting |
| Orders and clicks for conversion rate               | Observe before acting |
| Spend and sales for ACOS / ROAS                     | Observe before acting |
| Contribution margin for break-even ACOS             | Observe before acting |

## Safe action standard

Compare ACOS to the break-even or target guardrail before raising, holding, or lowering a bid.

## Ask before saving a change

| Question                                  | If the answer is “no”                         |
| ----------------------------------------- | --------------------------------------------- |
| Can I point to evidence?                  | Watch, research, or request the missing data. |
| Is the action within my permission level? | Notify or escalate.                           |
| Does it change only one variable?         | Split the actions into separate tests.        |
| Is there a guardrail and review date?     | Do not execute yet.                           |

## Core vocabulary

| Term  | Meaning                                  |
| ----- | ---------------------------------------- |
| CTR   | Clicks divided by impressions.           |
| CPC   | Spend divided by clicks.                 |
| CVR   | Orders divided by clicks.                |
| ACOS  | Ad spend divided by ad-attributed sales. |
| ROAS  | Ad-attributed sales divided by ad spend. |
| TACoS | Ad spend divided by total sales.         |
