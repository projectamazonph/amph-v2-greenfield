# Weekly Optimization SOP

## Purpose

Use this guide in Module 9. It protects the ability to learn from account changes.

## Standard cadence

| Step        | Required output                                      |
| ----------- | ---------------------------------------------------- |
| Observe     | Weekly baseline snapshot.                            |
| Diagnose    | Short statement of the likely leak or opportunity.   |
| Hypothesize | Testable explanation and expected signal.            |
| Change      | One variable only, within permission limits.         |
| Log         | Baseline, action, guardrail, owner, and review date. |
| Review      | Result, interpretation, and next action.             |

## Quality check

If you cannot say what changed and what evidence triggered it, the entry is not an optimization record yet. Rebuild it before execution.
