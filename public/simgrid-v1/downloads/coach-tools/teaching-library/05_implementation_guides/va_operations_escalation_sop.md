# VA Operations and Escalation SOP

## Purpose

Use this guide in Module 11 to make work repeatable and accountable across a PPC team.

## Core workflow

1. Read the assigned objective, target, and permission rule.
2. Inspect the agreed evidence source.
3. Create the required artifact: audit, harvest, experiment, report, or escalation record.
4. Execute only if the permission level is Independent or Notify.
5. For Approval-required actions, send a concise decision request and wait for the named owner.
6. Log the outcome and communicate the next checkpoint.

## Escalate when

The action changes client budget, price, listing content, access, strategy outside the agreed scope, or creates a risk the operator cannot evaluate confidently. A documented escalation is good operations, not a delay.
