# Weekly Search-Term Harvest Guide

## Purpose

Use this guide in Module 8. Harvesting converts raw search-term data into controlled campaign structure.

## Run order

1. Export or review the search-term evidence for the agreed window.
2. Check relevance before interpreting an efficiency ratio.
3. Apply the classification: Graduate, Negative, Lower / repair, or Watch.
4. Send each action to a destination campaign, negative level, or next review date.
5. Record the action in the Search-Term Harvest Log and do not mix it with unrelated bid changes.

## Decision gates

| Situation                                | Safe response                    |
| ---------------------------------------- | -------------------------------- |
| Relevant, profitable, enough evidence    | Graduate to controlled coverage. |
| Irrelevant with material clicks or spend | Add the appropriate negative.    |
| Relevant but above economic guardrail    | Lower or repair, then review.    |
| Low-volume or conflicting signal         | Watch and collect evidence.      |
