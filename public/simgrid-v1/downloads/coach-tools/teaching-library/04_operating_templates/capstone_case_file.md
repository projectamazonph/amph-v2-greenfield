## Evidence bundle

| Artifact                              | Included? | What it proves                             |
| ------------------------------------- | --------- | ------------------------------------------ |
| Listing readiness audit               | Yes / No  | The traffic decision was conversion-aware. |
| Campaign blueprint                    | Yes / No  | Structure had a named purpose.             |
| Search-term harvest or experiment log | Yes / No  | Action came from evidence.                 |
| Change record                         | Yes / No  | One-variable control and guardrail.        |
| Client report narrative               | Yes / No  | Decision can be communicated plainly.      |

## Reflection

1. What was your strongest evidence?
2. What alternative explanation did you rule out?
3. What did you not change, and why?
4. What would require client approval before the next step?
