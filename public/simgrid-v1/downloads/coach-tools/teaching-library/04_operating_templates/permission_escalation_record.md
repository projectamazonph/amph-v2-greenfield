# Permission and Escalation Record

## Use

Use this in Module 11 whenever an action has a client-impact, budget, listing, or access-control risk.

| Proposed action | Evidence | Permission level                         | Can execute now? | Notify / approver | Required message | Decision deadline | Final outcome |
| --------------- | -------- | ---------------------------------------- | ---------------- | ----------------- | ---------------- | ----------------- | ------------- |
|                 |          | Independent / Notify / Approval-required | Yes / No         |                   |                  |                   |               |

## Communication prompt

> **Observed:** [evidence]. **Recommendation:** [smallest safe action]. **Reason:** [business impact]. **Guardrail:** [what will be protected]. **Decision requested:** [approval, input, or acknowledgement] by [date].

## Permission rule

Do not use “I thought it was okay” as a substitute for an agreed operating boundary. When in doubt, document and escalate.
