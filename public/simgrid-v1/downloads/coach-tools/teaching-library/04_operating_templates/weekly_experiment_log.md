## Weekly cadence

| Day       | Operator action                                      | Evidence artifact |
| --------- | ---------------------------------------------------- | ----------------- |
| Monday    | Pull reports and identify the top decision question. | Baseline snapshot |
| Tuesday   | Diagnose and write the single-variable hypothesis.   | Experiment record |
| Wednesday | Execute within permission limits.                    | Change log        |
| Friday    | Review early signals and update the next checkpoint. | Result note       |
