# Four-Week Launch Brief

## Use

Use this in Module 6 to turn setup into a controlled learning plan. A launch is not complete when campaigns are live; it is complete when the team knows what evidence to inspect next.

| Launch component                    | Entry                           |
| ----------------------------------- | ------------------------------- |
| Product / ASIN                      |                                 |
| Objective                           |                                 |
| Listing readiness gate              | Ready / Repair first / Escalate |
| Target ACOS or break-even guardrail |                                 |
| Daily budget cap                    |                                 |
| Owner / approver                    |                                 |

| Week | Learning question                             | Planned action | Evidence to capture | Guardrail | Review date | Decision after review |
| ---: | --------------------------------------------- | -------------- | ------------------- | --------- | ----------- | --------------------- |
|    1 | Is the structure serving relevant traffic?    |                |                     |           |             |                       |
|    2 | Which search terms show credible intent?      |                |                     |           |             |                       |
|    3 | What can be graduated, blocked, or repaired?  |                |                     |           |             |                       |
|    4 | What should be scaled, held, or restructured? |                |                     |           |             |                       |
