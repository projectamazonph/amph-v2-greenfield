# Module 4 Field Handout — Keywords & Match Types

## The job

By the end of this module, you should be able to **Distinguish keyword versus search term; apply broad, phrase, exact, and negatives; research terms.** The required practice handoff is **Keyword Lab + Search Term Triage** (`keyword-lab.html / search-triage.html`), with a target of **75% each / 70% quiz**.

> **Operating rule:** A keyword is your instruction; a search term is the shopper evidence you must classify.

## What to look for

- **1.** Search-term relevance
- **2.** Click and order volume
- **3.** ACOS versus margin guardrail
- **4.** Match-type role and negative coverage

## Worked thinking

A profitable, relevant search term may graduate to Exact. An irrelevant high-click search term should be blocked with a negative, not rescued with a lower bid.

## Practice before you open the simulator

Classify six terms as graduate, lower / repair, negative, or watch. Write the evidence that justifies each classification.

## Decision standard

Promote proven relevance, block waste, lower only when relevance remains plausible, and watch when evidence is insufficient.

## Key language

| Term        | Plain-language meaning                                            |
| ----------- | ----------------------------------------------------------------- |
| Keyword     | A targeting instruction supplied by the advertiser.               |
| Search term | The shopper query that actually triggered an ad.                  |
| Broad       | A discovery-oriented match type with the widest controlled reach. |
| Phrase      | A match type that preserves phrase-level intent with variation.   |
| Exact       | A high-control match type for proven intent.                      |
| Negative    | An exclusion that blocks unwanted matching.                       |

## Exit ticket

Write one sentence for each prompt before moving on: What is the observed evidence? What is your smallest safe action? What guardrail or review date will tell you whether the action worked?
