# Facilitator Observation Scorecard

## Use

Score learner practice during simulator debrief. Rate each dimension from 1 (not yet visible) to 4 (repeatable without prompting).

| Dimension           | 1                       | 2                    | 3                            | 4                                                          | Score |
| ------------------- | ----------------------- | -------------------- | ---------------------------- | ---------------------------------------------------------- | ----: |
| Evidence reading    | Names metrics only      | Notices a signal     | Connects signal to diagnosis | Selects relevant evidence and rejects distractions         |       |
| Decision quality    | Suggests generic action | Action lacks control | Action matches evidence      | Smallest safe action with guardrail and review date        |       |
| Economic reasoning  | Uses no guardrail       | Names ACOS only      | Compares to a target         | Uses margin / target and denominator logic                 |       |
| Operational control | No owner or record      | Partial record       | Names owner and date         | Uses permission, change log, and checkpoint consistently   |       |
| Communication       | Vague explanation       | Names action         | Explains reason              | Communicates result, driver, action, guardrail, checkpoint |       |
