# Decision Quality Rubric

## Use

Apply this rubric to worksheets, change records, reports, and capstone submissions.

| Criterion     | Beginning                  | Developing             | Proficient               | Advanced                                                 |
| ------------- | -------------------------- | ---------------------- | ------------------------ | -------------------------------------------------------- |
| Evidence      | Assertion without evidence | Cites a metric         | Uses relevant evidence   | Weighs evidence and rules out alternatives               |
| Diagnosis     | Vague “optimize” language  | Names a likely issue   | Explains a causal link   | Prioritizes the earliest confirmed failure point         |
| Action        | Broad or risky change      | Action lacks a control | Smallest safe action     | Action includes destination, owner, and permission logic |
| Guardrail     | None                       | Generic caution        | Clear threshold or limit | Guardrail links to commercial risk and checkpoint        |
| Learning loop | No review plan             | Review date only       | Result and next action   | Documents outcome, interpretation, and reusable learning |
