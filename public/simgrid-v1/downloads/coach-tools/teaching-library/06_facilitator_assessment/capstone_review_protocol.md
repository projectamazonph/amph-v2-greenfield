# Capstone Review Protocol

## Submission rule

Learners submit the Capstone Case File plus a listing readiness audit, campaign blueprint, evidence log, controlled-change record, and client narrative. The program capstone target is 85%.

## Review sequence

1. Verify that the business objective and baseline are explicit.
2. Check that listing readiness and troubleshooting order were considered before PPC action.
3. Evaluate campaign / keyword structure and economic guardrails.
4. Confirm the learner selected one controlled action and observed the permission boundary.
5. Review the written narrative for result, driver, action, guardrail, and checkpoint.
6. Score with the Decision Quality Rubric and agree the next supervised operating task.

## Pass decision

| Outcome                        | Meaning                                                     | Next step                                           |
| ------------------------------ | ----------------------------------------------------------- | --------------------------------------------------- |
| Ready for supervised operation | Consistently uses evidence, controls, and communication.    | Assign a bounded account workflow.                  |
| Ready with targeted practice   | Core reasoning is sound but one skill is inconsistent.      | Repeat named simulator and artifact.                |
| Not yet ready                  | Key evidence, control, or permission behaviors are missing. | Revisit modules and resubmit the affected artifact. |
