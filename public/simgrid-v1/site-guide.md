# Project Amazon PH Academy SimGrid: Public Site Guide

> Project Amazon PH Academy SimGrid is a browser-based practice environment for Amazon PPC learning. It is designed for Filipino virtual assistants, learners, and instructors who need to move from simple explanations to guided simulator practice.

## What the project provides

The project combines three learning surfaces. **PPC Coach** provides a 12-module learning path. **SimGrid** provides interactive practice tools for campaign setup, keywords, bids, budgets, search terms, reporting, listing readiness, onboarding, and capstone work. **Coach Tools** provides beginner-first teaching decks, worksheets, scenario cards, evidence templates, and an expanded resource library.

## How to use the learning path

Learners with no Amazon background can begin with [VA Start Here](https://projectamazonph.github.io/amazon-ph-simulators/start-here.html), which provides a plain-English quick glossary and safe first-session plan. Then they can begin [PPC Coach](https://projectamazonph.github.io/amazon-ph-simulators/ppc-coach.html), complete each module’s explanation and quiz, and practice in the assigned simulator. The [Student Guide](https://projectamazonph.github.io/amazon-ph-simulators/learn/guide.html) describes the wider sequence. Instructors can pair the module lesson with a [teaching deck](https://projectamazonph.github.io/amazon-ph-simulators/coach-decks.html) and the linked learner materials in [Coach Tools](https://projectamazonph.github.io/amazon-ph-simulators/coach-tools.html).

## Simulator collection

The core simulator collection includes AdConsole Pro, Keyword Lab, Search Term Triage, SQP Studio, Bid Decisions, Campaign Architect, Account Audit, Client Onboarding, Capstone Sequence, Bulk File Simulator, BuyBox Dojo, and Pacing Deck. The [Control Hub](https://projectamazonph.github.io/amazon-ph-simulators/index.html#simulator-library) is the authoritative public directory.

## Important use note

The project teaches decision-making through examples and browser-based practice. A learner should collect evidence, follow the assigned steps, and seek the appropriate review before applying a strategy change to a real client account.
