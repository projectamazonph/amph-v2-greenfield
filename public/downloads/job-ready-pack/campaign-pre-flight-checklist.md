# Campaign Pre-Flight Checklist

A pre-launch checklist you run on every new Sponsored Products campaign
before flipping the budget on. Use the worked example below to study how a
real campaign passed each gate, then print the blank copy and run the same
gates on your own campaign before launch.

Version: 2026-10-11. Pair with Module 4 lesson 4.3 (Campaign Structure).

---

## How to use this template

- Run it the same day you create the campaign, before any spend turns on.
- Anything that fails goes back to the campaign editor before launch; do
  not "launch and fix later". A campaign that misses two or more of these
  gates usually wastes the first week's budget.
- File the completed copy under the campaign name in your client folder
  (for example, `clients/acme-co/q4-2026/auto-water-bottle/preflight.md`).

## Worked example — Auto Water Bottle, Sponsored Products, manual exact

Client: Acme Co. New ASIN: B0CXYZ1234 ("Stainless Auto Water Bottle 32oz").
Target ACOS: 25%. Daily budget: ₱500.

### 1. Campaign settings

| Gate | Required | Result |
| --- | --- | --- |
| Campaign name follows naming convention | yes | `SP-AUTO-WBOTTLE-32OZ-EXACT-MAN` |
| Campaign type | Sponsored Products | Sponsored Products |
| Targeting type | Manual | Manual |
| Start date recorded in change log | yes | 2026-09-15 |
| Daily budget documented in the brief | yes | ₱500 (within ₱400-₱600 range) |
| End date or review date set | yes | Review on 2026-09-29 (14 days) |

### 2. Ad group structure

| Gate | Required | Result |
| --- | --- | --- |
| One ad group per theme | yes | 1 ad group: "exact_match_core" |
| Theme reflects a clear intent | yes | Exact-match purchasers who already converted |
| Ad group name mirrors campaign name | yes | `AG-EXACT_CORE` |

### 3. Keyword set

| Gate | Required | Result |
| --- | --- | --- |
| Keywords sourced from the brief, not invented | yes | Brief listed "stainless water bottle 32oz" as a primary phrase |
| Match type matches intent | yes | Exact (high-intent traffic from past search terms) |
| Initial bid in range from the bid calculator | yes | ₱18 (bid calculator midpoint for ₱1,450 AOV) |
| Negatives from the most recent STR pasted in | yes | "kids", "leak proof", "glass" added as negative exact |
| No brand keywords without client approval | yes | None present |

### 4. Ads

| Gate | Required | Result |
| --- | --- | --- |
| At least 3 headlines in the headline pool | yes | 4 headlines written |
| Headlines reference the ASIN's actual differentiators | yes | "32oz", "stainless", "BPA-free" all appear in the listing |
| At least one headline includes the price or promo | yes | "Free shipping today" |
| Default bid set explicitly | yes | ₱18 (same as keyword bid, no auto strategy yet) |

### 5. Tracking

| Gate | Required | Result |
| --- | --- | --- |
| Brand tag applied to the campaign | yes | `brand=amph` (matches naming convention) |
| UTM parameters on any external links | yes | n/a (Sponsored Products only) |
| Conversion event firing for the ASIN | yes | Brand Analytics says yes (last checked 2026-09-14) |
| Bulk sheet has the campaign row ready | yes | Row added to `q4-2026-auto-water-bottle-bulk.xlsx` |

### 6. Sign-off

- Account manager: J. Cruz, 2026-09-15, 09:42 PHT
- VA who built it: P. Santos, 2026-09-15, 09:38 PHT
- Client review: not required for exact-match follow-on campaigns

## Notes

- If three or more gates fail, do not launch. Fix the gaps, then re-run the
  checklist.
- File the completed copy under the campaign name in your client folder.
- This template covers Sponsored Products only. Sponsored Brands and
  Sponsored Display pre-flights add a placement and audience row each.
