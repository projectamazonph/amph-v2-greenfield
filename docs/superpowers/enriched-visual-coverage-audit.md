## Audit limitations

This is a source-level audit. It verifies directive presence, JSON validity, visual-type diversity, and learning-contract headings. It does not replace browser-based visual inspection of every lesson at desktop and mobile widths, nor does it prove that every visual payload is pedagogically optimal. The 1.1 lesson is classified as legacy because it uses generic visual payloads rather than the dedicated semantic primitives, even though its visual count is high.
