# Next Enrichment Tranche

The next tranche covers the remaining high-leverage cluster from the rollout blueprint: onboarding lessons 0.1–0.3, portfolio lessons 5.1 and 5.3, and competitive-intelligence lessons 8.1 and 8.2. Lessons 5.2 and 8.3 already exercise the timeline and competitive-gap primitives, so this tranche extends the system instead of duplicating those visuals.

| Lesson family | New primitive | Teaching job |
| --- | --- | --- |
| Onboarding | `LessonPathway` | Make the course loop, practice surfaces, and progression visible |
| First simulation | `SimulationBriefBuilder` | Turn client context into an inspectable pre-flight brief |
| Portfolio strategy | `PortfolioMap` | Show portfolio → campaign grouping, budget share, and control boundary |
| Seasonal strategy | `SeasonalCalendar` | Compare pre-season, in-season, and post-season decisions on one calendar |
| Brand Analytics | `EvidenceLedger` | Connect report inputs to signal quality, PPC implication, and next evidence check |
| Share of voice | `SovPositioner` | Place the account on a strategy spectrum and show the posture that follows |

The components will use the same MDX JSON-directive transport, semantic controls, responsive CSS Modules, and reduced-motion behavior already established in the earlier tranches. Representative integrations will target 0.1, 0.3, 5.1, 5.3, 8.1, and 8.2.
